# Air-Ground Security System — MVP

Автономная бюджетная система охраны гражданских объектов с контролем воздушного пространства и уведомлениями на смартфон владельца.

**Стек:** Ubuntu 20.04 LTS · ROS 1 Noetic · Docker · Git · Bash

---

## Концепция

Система работает **полностью автономно, без оператора**. Главная функция в Фазе 1 — **контроль воздушного пространства**: дрон патрулирует воздух, детектирует несанкционированные БПЛА и перехватывает их.

### Три эшелона

- **Воздушный эшелон (Фаза 1)**: дрон — патрулирует воздух, детектирует чужие БПЛА, перехватывает
- **Наземный эшелон (Фаза 2-3)**: камеры 360°, PIR-датчики — постоянный мониторинг периметра
- **Управление**: автономный сервер (Ubuntu + ROS), владелец получает уведомления на смартфон

---

## Сценарии охраны (автоматические, без оператора)

### 1. Контроль воздушного пространства (Фаза 1)

При обнаружении несанкционированного дрона над объектом:

- Детектор чужого БПЛА фиксирует сигнал (в Фазе 1 — симуляция, в Фазе 2 — реальный детектор).
- Система определяет азимут и приблизительную дальность.
- Охранный дрон прерывает воздушное патрулирование и вылетает на перехват.
- Владелец получает тревожное уведомление: "Неизвестный дрон обнаружен над участком".
- Видео с камер автоматически пишется в облако для возможного обращения в полицию.

### 2. Охрана периметра (Фаза 2-3)

- PIR-датчик или камера 360° фиксирует движение на границе объекта.
- Система автоматически разворачивает PTZ-камеру на точку тревоги.
- Одновременно:
  - Дрон взлетает и летит к точке нарушения для верификации.
  - Владелец получает push-уведомление на смартфон: "Тревога: движение в секторе А3".
  - В уведомлении — кнопка "Открыть видео" для просмотра трансляции с дрона.

### 3. Плановый облёт внешнего контура (Фаза 2-3)

Если тревог нет — дрон автоматически патрулирует объект:

- Взлёт по расписанию (каждые 30–60 минут).
- Облёт по заранее заданному внешнему контуру (waypoints).
- Во время полёта:
  - Обзорная камера сканирует территорию.
  - LiDAR контролирует целостность забора и периметра.
- После облёта — автоматический возврат и зарядка.
- На смартфон приходит краткий отчёт: "✅ Облёт завершён, нарушений нет" или "⚠️ Обнаружено 2 подозрительных объекта".

### 4. Гибридная реакция (Фаза 3)

Все сценарии работают параллельно:

- Воздушное патрулирование прерывается при обнаружении чужого БПЛА.
- Плановый облёт прерывается при тревоге периметра.
- После отработки тревоги дрон возвращается к прерванному маршруту.
- Владелец в любой момент со смартфона может:
  - Запустить внеплановый облёт.
  - Просмотреть live-видео с любой камеры.
  - Посмотреть историю облётов и тревог.
  - Ручной перехват управления дроном (для опытных пользователей).

**Важно:** всё это работает автоматически. Владелец может не открывать приложение неделями — система пришлёт уведомление только когда это действительно нужно.

## Алгоритм управления дроном (ядро системы)

### Конечный автомат состояний

    ┌─────────┐    /drone/command: takeoff
    │  IDLE   │ ─────────────────────────────► TAKEOFF
    └─────────┘                                    │
         ▲                                         │ достигнута высота
         │                                         ▼
         │                                     ┌──────────────┐
         │ /drone/command: land               │ AIR_PATROL   │◄────────┐
         │                                     └────┬─────────┘         │
         │                                          │                   │
         │                          /intruder/      │                   │
         │                          detected        │                   │
         │                                          ▼                   │
         │                                     ┌──────────────┐         │
         └─────────────────────────────────────│  INTERCEPT   │─────────┘
                                               └──────────────┘
                                                    │
                                                    ▼
                                                 LAND

### Состояния

| Состояние | Описание | Триггер входа | Триггер выхода |
|---|---|---|---|
| `IDLE` | Дрон на базе, заряжается | `/drone/command: takeoff` | — |
| `TAKEOFF` | Взлёт на рабочую высоту | — | достигнута высота |
| `AIR_PATROL` | Воздушное патрулирование зоны | `/intruder/detected` | завершён маршрут |
| `INTERCEPT` | Перехват чужого БПЛА | — | цель достигнута |
| `LAND` | Посадка на базу | — | посадка завершена |

### Узлы управления

| Узел | Назначение |
|---|---|
| `drone_controller.py` | Конечный автомат управления дроном |
| `air_patrol_planner.py` | Планирование воздушного патруля |
| `intruder_detector.py` | Детекция чужого БПЛА (симуляция в Фазе 1) |
| `intruder_simulator.py` | Симулятор чужого БПЛА (для тестов) |

|---|---|---|---|
| Pixhawk (FC) | USB/UART | /dev/ttyACM0 | mavros |
| GPS u-blox M9N | UART (через FC) | — | mavros |
| Обзорная камера | USB | /dev/video0 | usb_cam |
| RTL-SDR v3 | USB | /dev/bus/usb/... | gr-osmosdr (опц.) |

| 4G/LTE модем | USB | /dev/ttyUSB2 | свой узел (Фаза 2) |

## Быстрый старт

Клонирование:

    git clone git@github.com:Gibrin/air-ground-security-mvp.git
    cd air-ground-security-mvp

Установка зависимостей:

    ./scripts/00_install_base.sh
    ./scripts/01_install_ros_packages.sh
    ./scripts/02_setup_ssh.sh
    ./scripts/03_setup_devices.sh

Сборка и запуск:

    ./scripts/04_build_workspace.sh
    source devel/setup.bash
    roslaunch air_ground_bringup system.launch

## Docker

Сборка и запуск:

    docker build -t air-ground-security:mvp -f docker/Dockerfile .
    docker run -it --rm --privileged -v /dev:/dev -p 2222:2222 air-ground-security:mvp

## Топики ROS

| Топик | Тип | Источник | Назначение |
|---|---|---|---|
| `/drone/state` | `std_msgs/String` | `drone_controller` | Текущее состояние дрона |
| `/drone/position` | `geometry_msgs/Pose` | `drone_controller` | Текущая позиция дрона |
| `/drone/command` | `std_msgs/String` | внешние узлы | Команды управления |
| `/drone/setpoint` | `geometry_msgs/Point` | `drone_controller` | Целевая точка полёта |
| `/air_patrol/waypoints` | `geometry_msgs/PoseArray` | `air_patrol_planner` | Маршрут воздушного патруля |
| `/intruder/detected` | `std_msgs/Bool` | `intruder_detector` | Обнаружение чужого БПЛА |
| `/intruder/position` | `geometry_msgs/Point` | `intruder_detector` | Позиция чужого БПЛА |
| `/battery_state` | `sensor_msgs/BatteryState` | `battery_node` | Мониторинг заряда |
| `/camera/image_raw` | `sensor_msgs/Image` | `usb_cam` | Видео с камеры |
| `/alert/mobile` | `std_msgs/String` | `telegram_alert` | Уведомления на смартфон |
| `/pir/status` | `std_msgs/Bool` | `pir_simulator` | Тревога периметра (Фаза 2) |
| `/pir/location` | `geometry_msgs/Point` | `pir_simulator` | Координаты нарушения (Фаза 2) |
| `/rf/detected` | `std_msgs/Bool` | `rf_detector` | Обнаружение БПЛА по RF (Фаза 2) |
| `/video/stream` | `sensor_msgs/CompressedImage` | `video_stream` | Поток для WebRTC (Фаза 2) |
