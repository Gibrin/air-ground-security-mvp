#  Air-Ground Security System — MVP

Автономная бюджетная система охраны гражданских объектов (дача, склад, парковка, коттедж) с уведомлениями на смартфон владельца.

**Стек:** Ubuntu 20.04 LTS · ROS 1 Noetic · Docker · Git · Bash · MQTT · Telegram Bot

---

##  Концепция

Система работает **полностью автономно, без оператора**. Владелец объекта получает уведомления и видео прямо на смартфон через приложение или Telegram-бот.

### Три эшелона

- **Наземный эшелон**: камеры 360°, PIR-датчики, RF-детектор дронов — постоянный мониторинг
- **Воздушный эшелон**: дрон — вылетает только при тревоге или по расписанию облёта
- **Управление**: автономный сервер (Ubuntu + ROS), владелец получает уведомления на смартфон

---

##  Сценарии охраны (автоматические, без оператора)

### 1. Охрана периметра

- PIR-датчик или камера 360° фиксирует движение на границе объекта.
- Система автоматически разворачивает PTZ-камеру на точку тревоги.
- Одновременно:
  - Дрон взлетает и летит к точке нарушения для верификации.
  - Владелец получает push-уведомление на смартфон: "🚨 Тревога: движение в секторе А3".
  - В уведомлении — кнопка "Открыть видео" для просмотра трансляции с дрона.

### 2. Плановый облёт внешнего контура

Если тревог нет — дрон автоматически патрулирует объект:

- Взлёт по расписанию (каждые 30–60 минут).
- Облёт по заранее заданному внешнему контуру (waypoints).
- Во время полёта:
  - Обзорная камера сканирует территорию.
  - LiDAR контролирует целостность забора и периметра.
  - RTL-SDR ищет сигналы чужих БПЛА.
- После облёта — автоматический возврат и зарядка.
- На смартфон приходит краткий отчёт: "✅ Облёт завершён, нарушений нет" или "⚠️ Обнаружено 2 подозрительных объекта".

### 3. Контроль воздушного пространства

При обнаружении несанкционированного дрона над объектом:

- RF-детектор (RTL-SDR) фиксирует сигнал чужого БПЛА.
- Система определяет азимут и приблизительную дальность.
- Охранный дрон вылетает на перехват.
- Владелец получает тревожное уведомление: "⚠️ Неизвестный дрон обнаружен над участком".
- Видео с камер автоматически пишется в облако для возможного обращения в полицию.

### 4. Гибридная реакция

Все сценарии работают параллельно:

- Плановый облёт прерывается при тревоге периметра или обнаружении чужого БПЛА.
- После отработки тревоги дрон возвращается к прерванному маршруту.
- Владелец в любой момент со смартфона может:
  - Запустить внеплановый облёт.
  - Просмотреть live-видео с любой камеры.
  - Посмотреть историю облётов и тревог.
  - Ручной перехват управления дроном (для опытных пользователей).

##  Как владелец получает информацию

### Уведомления (push)

- Telegram-бот отправляет сообщения с фото и координатами.
- Push-уведомления через MQTT-брокер → мобильное приложение.
- SMS-уведомления для критичных тревог (опционально).

### Просмотр видео

- Live-трансляция с дрона через WebRTC на смартфон.
- Архивные записи облётов и тревог — в мобильном приложении.
- Возможность скачать видео для доказательств.

### Управление со смартфона

- Запуск / остановка патрулирования.
- Выбор точки для точечной проверки.
- Ручное управление дроном (виртуальный джойстик).
- Просмотр статуса системы: заряд, погода, история событий.

**Важно:** всё это работает автоматически. Владелец может не открывать приложение неделями — система пришлёт уведомление только когда это действительно нужно.

|---|---|---|---|
| Pixhawk (FC) | USB/UART | /dev/ttyACM0 | mavros |

| RTL-SDR v3 | USB | /dev/bus/usb/... | gr-osmosdr (опц.) |
| 4G/LTE модем | USB | /dev/ttyUSB2 | свой узел |

##  Быстрый старт

Клонирование:

    git clone git@github.com:Gibrin/air-ground-security-mvp.git
    cd air-ground-security-mvp

Установка зависимостей:

    ./scripts/00_install_base.sh
    ./scripts/01_install_ros_packages.sh
    ./scripts/02_setup_ssh.sh
    ./scripts/03_setup_devices.sh

Сборка и запуск:

    ./scripts/04_build_workspace.sh
    source devel/setup.bash
    roslaunch air_ground_bringup system.launch

## Docker

Сборка и запуск:

    docker build -t air-ground-security:mvp -f docker/Dockerfile .
    docker run -it --rm --privileged -v /dev:/dev -p 2222:2222 air-ground-security:mvp
    ssh -p 2222 robot@localhost

| /video/stream | sensor_msgs/CompressedImage | камера | Поток для WebRTC |
