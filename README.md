# Air-Ground Security System — MVP

Автономная бюджетная система охраны гражданских объектов (дача, склад, парковка, коттедж) с уведомлениями на смартфон владельца.

**Стек:** Ubuntu 20.04 LTS · ROS 1 Noetic · Docker · Git · Bash · MQTT · Telegram Bot

---

## Концепция

Система работает **полностью автономно, без оператора**. Владелец объекта получает уведомления и видео прямо на смартфон через приложение или Telegram-бот.

### Три эшелона

- **Наземный эшелон**: камеры 360°, PIR-датчики, RF-детектор дронов — постоянный мониторинг
- **Воздушный эшелон**: дрон — вылетает только при тревоге или по расписанию облёта
- **Управление**: автономный сервер (Ubuntu + ROS), владелец получает уведомления на смартфон

---

## Сценарии охраны (автоматические, без оператора)

### 1. Охрана периметра

- PIR-датчик или камера 360° фиксирует движение на границе объекта.
- Система автоматически разворачивает PTZ-камеру на точку тревоги.
- Одновременно:
  - Дрон взлетает и летит к точке нарушения для верификации.
  - Владелец получает push-уведомление на смартфон: "Тревога: движение в секторе А3".
  - В уведомлении — кнопка "Открыть видео" для просмотра трансляции с дрона.

### 2. Плановый облёт внешнего контура

Если тревог нет — дрон автоматически патрулирует объект:

- Взлёт по расписанию (каждые 30–60 минут).
- Облёт по заранее заданному внешнему контуру (waypoints).
- Во время полёта:
  - Обзорная камера сканирует территорию.
  - LiDAR контролирует целостность забора и периметра.
  - RTL-SDR ищет сигналы чужих БПЛА.
- После облёта — автоматический возврат и зарядка.
- На смартфон приходит краткий отчёт: "Облёт завершён, нарушений нет" или "Обнаружено 2 подозрительных объекта".

### 3. Контроль воздушного пространства

При обнаружении несанкционированного дрона над объектом:

- RF-детектор (RTL-SDR) фиксирует сигнал чужого БПЛА.
- Система определяет азимут и приблизительную дальность.
- Охранный дрон вылетает на перехват.
- Владелец получает тревожное уведомление: "Неизвестный дрон обнаружен над участком".
- Видео с камер автоматически пишется в облако для возможного обращения в полицию.

### 4. Гибридная реакция

Все сценарии работают параллельно:

- Плановый облёт прерывается при тревоге периметра или обнаружении чужого БПЛА.
- После отработки тревоги дрон возвращается к прерванному маршруту.
- Владелец в любой момент со смартфона может:
  - Запустить внеплановый облёт.
  - Просмотреть live-видео с любой камеры.
  - Посмотреть историю облётов и тревог.
  - Ручной перехват управления дроном (для опытных пользователей).

**Важно:** всё это работает автоматически. Владелец может не открывать приложение неделями — система пришлёт уведомление только когда это действительно нужно.

## План развития системы

### Матрица по функциям

| Функция | Фаза 1 (текущая) | Фаза 2 | Фаза 3 |
|---|---|---|---|
| 1. Контроль периметра | Симулятор (заглушка) | Реальные датчики | Интеграция с системами |
| 2. Облёт внешнего контура | Описание (без кода) | Реальный облёт | Адаптивные маршруты |
| 3. Контроль воздуха | Описание (без кода) | Базовый RF-детектор | Полная система |
| 4. Мобильная интеграция | `telegram_alert_node.py` | Полноценный бот | Облако + управление |

### Что реализовано в Фазе 1 (текущая)

**Контроль периметра:**
- ✅ `pir_simulator_node.py` — симулятор датчиков периметра
- ✅ Топик `/pir/status` с координатами нарушения
- ⚠️ Реальные датчики подключаются в Фазе 2

**Облёт внешнего контура:**
- ✅ Описание архитектуры в `docs/patrol.md`
- ⚠️ Реальный облёт через MAVROS в Фазе 2

**Контроль воздушного пространства:**
- ✅ Описание архитектуры в `docs/counter_drone.md`
- ⚠️ Реальный RF-детектор в Фазе 2

**Мобильная интеграция:**
- ✅ `telegram_alert_node.py` — отправка уведомлений
- ✅ Топик `/alert/mobile`
- ⚠️ Полноценное мобильное приложение в Фазе 2

### Что планируется в Фазе 2

**Контроль периметра:**
- Реальные PIR-датчики (4–8 шт.)
- Камеры 360° с PTZ-управлением
- Акустические датчики для детекции шагов

**Облёт внешнего контура:**
- Реальный облёт по waypoints через MAVROS
- Автоматическая зарядка на базе
- Обход препятствий через LiDAR

**Контроль воздушного пространства:**
- Базовый RF-детектор (RTL-SDR)
- Акустический массив для детекции БПЛА
- Автоматический вылет на перехват

**Мобильная интеграция:**
- Полноценный Telegram-бот с командами
- Реальный WebRTC-стриминг видео
- Мобильное приложение (базовое)

### Что планируется в Фазе 3

**Контроль периметра:**
- Интеграция с существующими системами безопасности
- Тепловизоры для ночного видения
- Машинное обучение для классификации угроз

**Облёт внешнего контура:**
- Адаптивные маршруты с учётом погоды
- Многодроновое патрулирование
- Автономная навигация без GPS (Vision-based)

**Контроль воздушного пространства:**
- Полная система обнаружения и нейтрализации
- Радар для дальнего обнаружения
- Автоматическое сопровождение чужого БПЛА

**Мобильная интеграция:**
- Нативное мобильное приложение (Flutter/React Native)
- Облачное хранение видео
- Ручное управление дроном со смартфона
- История облётов и тревог

**Полное описание архитектуры мобильной интеграции:** [см. документацию](src/air_ground_bringup/docs/mobile_integration.md)

## Состав системы (проектно)

| Устройство | Интерфейс | Linux-интерфейс | ROS-пакет |
|---|---|---|---|
| Pixhawk (FC) | USB/UART | /dev/ttyACM0 | mavros |
| GPS u-blox M9N | UART (через FC) | — | mavros |
| RPLidar A1 | USB | /dev/ttyUSB0 | rplidar_ros |
| Обзорная камера | USB | /dev/video0 | usb_cam |
| PIR-датчики | GPIO → MCU | — | свой узел (симуляция) |
| Аккумулятор (BMS) | I2C / sysfs | /sys/class/power_supply/BAT0 | свой узел |
| RTL-SDR v3 | USB | /dev/bus/usb/... | gr-osmosdr (опц.) |
| 4G/LTE модем | USB | /dev/ttyUSB2 | свой узел (Фаза 2) |

## Быстрый старт

Клонирование:

    git clone git@github.com:Gibrin/air-ground-security-mvp.git
    cd air-ground-security-mvp

Установка зависимостей:

    ./scripts/00_install_base.sh
    ./scripts/01_install_ros_packages.sh
    ./scripts/02_setup_ssh.sh
    ./scripts/03_setup_devices.sh

Сборка и запуск:

    ./scripts/04_build_workspace.sh
    source devel/setup.bash
    roslaunch air_ground_bringup system.launch

## Топики ROS

| Топик | Тип | Источник | Назначение |
|---|---|---|---|
| /battery_state | sensor_msgs/BatteryState | sysfs BAT0 | Мониторинг заряда |
| /camera/image_raw | sensor_msgs/Image | /dev/video0 | Видео с камеры |
| /pir/status | std_msgs/Bool | симулятор | Тревога периметра |
| /pir/location | geometry_msgs/Point | симулятор | Координаты нарушения |
