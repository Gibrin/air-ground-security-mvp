# Air-Ground Security System — Матрица развития по фазам

## Философия разработки

Проект развивается итеративно: от MVP (Фаза 1) к полноценной системе
(Фаза 3). Каждая фаза добавляет функционал, не ломая предыдущий.
Главная функция Фазы 1 — КОНТРОЛЬ ВОЗДУШНОГО ПРОСТРАНСТВА.

ВАЖНО: Контроль периметра и облёт внешнего контура — это ОТДЕЛЬНЫЕ
функции, которые реализуются в Фазах 2-3. Они НЕ смешиваются с
контролем воздушного пространства.

## Матрица функций по фазам

| Функция | Фаза 1 (текущая) | Фаза 2 | Фаза 3 |
|---|---|---|---|
| 0. Управление дроном для контроля воздуха | Симулятор + алгоритм воздушного патрулирования и перехвата | Реальный MAVROS + детектор | Полная система нейтрализации |
| 1. Контроль периметра | Описание (без кода) | Симулятор датчиков | Реальные датчики |
| 2. Облёт внешнего контура | Описание (без кода) | Базовый облёт | Реальный облёт |
| 3. Мобильная интеграция | Заглушка алертов | Полноценный бот | Облако + управление |

## Фаза 1 — MVP (текущая)

Цель: подготовить всю инфраструктуру для системы управления роботом
и реализовать ядро — контроль воздушного пространства в симуляции.

### Реализовано

- Конечный автомат управления дроном (drone_controller.py):
  IDLE -> TAKEOFF -> AIR_PATROL -> INTERCEPT -> LAND
- Планировщик воздушного патруля (air_patrol_planner.py)
- Детектор чужих БПЛА (intruder_detector.py, симуляция)
- Симулятор чужого БПЛА (intruder_simulator.py)
- Симулятор дрона (drone_simulator.py, публикация позиции)
- Мониторинг батареи ноутбука (battery_node.py, реальное устройство)
- Скрипты установки (scripts/00-04)
- Docker-образ с ROS Noetic и SSH
- Визуализация в RViz и RQT

### Не реализовано (переносится в Фазу 2)

- Реальный драйвер дрона (MAVROS + PX4)
- Реальный детектор БПЛА
- Датчики периметра (PIR, камеры)
- Полноценные мобильные уведомления

## Фаза 2 — Интеграция реального железа

Цель: заменить симуляторы реальными компонентами.

### План

- Замена drone_simulator.py на реальный MAVROS + PX4
- Подключение реального детектора БПЛА (замена intruder_detector.py)
- Симулятор датчиков периметра (PIR, камеры 360)
- Базовый облёт внешнего контура
- Полноценный Telegram-бот для уведомлений

## Фаза 3 — Полная система

Цель: автономная система охраны без оператора.

### План

- Полная система нейтрализации чужих БПЛА
- Реальные датчики периметра
- Реальный облёт внешнего контура
- Облачная интеграция и удалённое управление

## Текущее состояние

Фаза 1 завершена. Система проверена: полный цикл FSM
(IDLE -> TAKEOFF -> AIR_PATROL -> INTERCEPT -> AIR_PATROL)
работает, батарея визуализирована в RQT, Docker и SSH проверены.
