# Борьба с чужими БПЛА (Counter-Drone)

## Назначение

Обнаружение и перехват несанкционированных БПЛА в воздушном
пространстве охраняемого объекта (дача, склад, парковка, коттедж).
Это ядро Фазы 1 системы Air-Ground Security MVP.

## Модель угрозы

Несанкционированный БПЛА (нарушитель) может:

- Вести несанкционированное наблюдение за объектом
- Представлять опасность для людей и имущества
- Нарушать воздушное пространство объекта

Характеристики нарушителя (типичные гражданские БПЛА):

- Скорость: 5-20 м/с
- Высота: 5-50 м
- Радиус действия: до нескольких км

## Архитектура Counter-Drone

Два компонента:

1. ДЕТЕКЦИЯ — обнаружение нарушителя (intruder_detector.py)
2. НЕЙТРАЛИЗАЦИЯ — перехват дроном-охранником (drone_controller.py)

Поток данных:

    нарушитель -> детекция -> /intruder/detected -> FSM -> перехват

## Детекция

### Фаза 1 (текущая): симуляция

- intruder_detector.py — логика обнаружения (вероятностная модель)
- intruder_simulator.py — физика движения нарушителя
- Ручной триггер для отладки: /intruder_detector/trigger

Режимы симуляции нарушителя:

- linear — линейное вторжение в зону объекта
- circle — круговое движение вокруг зоны
- hover — зависание (наблюдение)

### Фаза 2: реальный детектор

Замена intruder_detector.py на реальный источник данных:

- RF-детектор (анализ радиоканала управления БПЛА)
- Акустический детектор (микрофонные массивы)
- Радиолокатор (малые РЛС)
- Оптический детектор (камеры + CV)

Интерфейс не меняется: детектор публикует те же топики
/intruder/detected и /intruder/position.

## Нейтрализация

### Фаза 1 (текущая): перехват сближением

- Дрон-охранник наводится методом погони (pursuit guidance)
- Успешный перехват: дистанция < 2 м
- После перехвата — возврат в патруль

### Фаза 3: полная система нейтрализации

Варианты физического воздействия (для будущих фаз):

- Сетемёт (захват нарушителя сетью)
- Таран защитным кожухом
- Радиоэлектронное подавление канала управления
- Принуждение к посадке (GPS-спуфинг, только для спецслужб)

## Топики Counter-Drone

| Топик | Тип | Назначение |
|---|---|---|
| /intruder/detected | std_msgs/Bool | флаг обнаружения |
| /intruder/position | geometry_msgs/Point | позиция нарушителя |
| /intruder_detector/trigger | std_msgs/Empty | ручной триггер |
| /intruder_simulator/command | std_msgs/String | start / stop |

## Команды для тестирования

Запуск симуляции вторжения:

    rostopic pub --once /intruder_simulator/command std_msgs/String "data: 'start'"

Ручной триггер детектора:

    rostopic pub --once /intruder_detector/trigger std_msgs/Empty "{}"

## Правовые аспекты

ВАЖНО: система предназначена для ГРАЖДАНСКИХ объектов.

- Физическое воздействие на БПЛА регулируется законодательством
- В Фазе 1 и 2 используется только сближение и наблюдение
- Методы физического воздействия (Фаза 3) требуют
  отдельного юридического обоснования
- Владелец объекта получает уведомления, решение о действиях
  в спорных случаях остаётся за человеком (Фаза 3: облако)

## Проверенный сценарий (Фаза 1)

Перехват движущейся цели проверен на реальной системе:

    AIR_PATROL -> INTERCEPT -> (погоня) -> перехват 1.99 м -> AIR_PATROL

Лог: "Intercept successful (distance: 1.99 m)"
