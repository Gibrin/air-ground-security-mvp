# Облёт внешнего контура объекта

## Назначение

Визуальный осмотр границы охраняемого объекта (забор, ворота,
периметр участка) с воздуха. Это ОТДЕЛЬНАЯ функция системы,
НЕ смешиваемая с контролем воздушного пространства
(docs/drone_control.md) и мониторингом периметра (docs/perimeter.md).

## Отличия от воздушного патруля (AIR_PATROL)

Это две разные функции, несмотря на то, что обе выполняются дроном:

| Критерий | Воздушный патруль (AIR_PATROL) | Облёт контура |
|---|---|---|
| Назначение | Контроль воздушного пространства | Осмотр границы участка |
| Маршрут | Круг над центром объекта | По границе участка (периметру) |
| Высота | Рабочая высота (10-20 м) | Низкая высота (3-5 м) |
| Скорость | Стандартная | Медленная (для осмотра) |
| Камера | Не используется | Направлена вниз/вбок |
| Триггер | Автоматически (после взлёта) | По расписанию или команде |
| Фаза реализации | Фаза 1 (текущая) | Фаза 2-3 |

## Статус по фазам

| Фаза | Статус |
|---|---|
| Фаза 1 (текущая) | Описание (без кода) |
| Фаза 2 | Базовый облёт по заданному маршруту |
| Фаза 3 | Реальный облёт с анализом изображений |

В Фазе 1 код облёта НЕ разрабатывается — все ресурсы направлены
на контроль воздушного пространства. В future/ будут реализованы
узлы perimeter_patrol_planner и visual_inspector.

## Архитектура (проект на Фазы 2-3)

Компоненты:

- perimeter_patrol_planner — генерация маршрута по границе участка
- visual_inspector — узел обработки видеопотока с камеры дрона
- anomaly_detector — детектор аномалий на границе
  (повреждения забора, посторонние предметы)

Поток данных (Фаза 2+):

    планировщик -> setpoints -> дрон -> камера -> анализ -> алерты

## Сценарии использования

### Плановый облёт
- Запуск по расписанию (например, 2 раза в день)
- Команда: /drone/command: perimeter_patrol
- Запись видео во время облёта
- Отчёт владельцу через мобильные уведомления

### Внеочередной облёт
- Триггер: событие периметра (PIR-датчик)
- Дрон автоматически летит к точке срабатывания
- Визуальная проверка и передача видео владельцу

### Экстренный облёт
- Триггер: команда владельца через мобильное приложение
- Срочный вылет для проверки подозрительной зоны

## Топики (проект на Фазу 2)

| Топик | Тип | Назначение |
|---|---|---|
| /perimeter_patrol/waypoints | geometry_msgs/PoseArray | маршрут облёта |
| /perimeter_patrol/camera/image | sensor_msgs/Image | видеопоток с камеры |
| /perimeter_patrol/anomalies | std_msgs/String | обнаруженные аномалии |
| /drone/command | std_msgs/String | команда perimeter_patrol |

## Параметры маршрута (план)

- Контур объекта (последовательность GPS-точек или локальных координат)
- Высота облёта (3-5 м)
- Скорость облёта (2-3 м/с)
- Интервал снимков (каждые 5 м или по таймеру)
- Режим камеры (наклон вниз / в сторону от забора)
