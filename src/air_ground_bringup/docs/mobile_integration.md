# Мобильная интеграция и уведомления владельца

## Назначение

Система охраны Air-Ground Security работает ПОЛНОСТЬЮ АВТОНОМНО,
без оператора. Владелец объекта получает уведомления на смартфон
о всех критических событиях: обнаружении нарушителя, срабатывании
периметра, низком заряде батареи и статусе дрона.

## Статус по фазам

| Фаза | Статус |
|---|---|
| Фаза 1 (текущая) | Заглушка алертов (telegram_alert_node.py в планах) |
| Фаза 2 | Полноценный Telegram-бот с уведомлениями |
| Фаза 3 | Облачная платформа + мобильное приложение (iOS/Android) |

В Фазе 1 узел `telegram_alert_node.py` не реализован (закомментирован
в system.launch). Логирование событий происходит в консоль ROS и rqt_console.

## Архитектура (проект на Фазы 2-3)

Компоненты:

- telegram_alert_node.py — отправитель сообщений в Telegram
- event_aggregator — агрегатор событий от всех подсистем
- cloud_bridge — мост между локальной ROS-сетью и облаком (Фаза 3)

Поток данных:

    /intruder/detected  \
    /perimeter/events   -> event_aggregator -> telegram_alert_node -> Telegram API
    /battery_state      /

## Типы уведомлений

### 1. Критические (мгновенные)
- Обнаружение чужого БПЛА (воздушный эшелон)
- Успешный перехват нарушителя
- Срабатывание PIR-датчика (периметр)
- Аварийная посадка дрона (батарея < 10%)

### 2. Информационные (по расписанию или запросу)
- Ежедневный отчёт: "Система в норме, облётов: 2, инцидентов: 0"
- Статус батареи дрона при постановке на базу
- Погодные условия (если добавим метеодатчик)

### 3. Команды от владельца (Фаза 2+)
- `/status` — текущее состояние системы
- `/takeoff` — принудительный взлёт
- `/patrol` — запуск облёта периметра
- `/photo` — снимок с камеры дрона / периметра

## Безопасность и приватность

- Telegram-бот использует защищённый HTTPS API
- Токен бота хранится в переменных окружения (не в коде)
- Доступ к боту ограничен по `chat_id` (только владелец)
- В Фазе 3 (облако) трафик шифруется end-to-end
- Видео с камер не передаётся в облако без явного запроса владельца

## Интеграция с подсистемами

- Подписывается на `/intruder/detected` (docs/counter_drone.md)
- Подписывается на `/perimeter/events` (docs/perimeter.md)
- Подписывается на `/battery_state` (docs/drone_control.md)
- Отправляет статусы в `/mobile/status` для логирования

## Альтернативные каналы связи (план на будущее)

Помимо Telegram, система может поддерживать:
- SMS-шлюз (для критических алертов без интернета)
- Email-уведомления (для ежедневных отчётов)
- Push-уведомления через собственное мобильное приложение (Фаза 3)
- Сирена на объекте (локальное звуковое оповещение)
